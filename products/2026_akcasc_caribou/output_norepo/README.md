# AKCASC caribou daily products

Daily WRF 4km fields, clipped to the Porcupine Caribou Herd (PCH) summer study
area, May-Aug 2021-2024. Two formats of the same data: yearly NetCDF and
per-day GeoTIFF.

## Coverage

- **Period**: 1 May - 31 Aug, 2021-2024 (123 days/year, 492 days total)
- **Source**: daily downscaled ERA5/WRF output, 4km resolution
  (`era5_wrf_dscale_4km_*.nc`), WRF V4.5.1
- **Spatial clip**: PCH summer study area shapefile
  (`../input_external/PCH_StudyArea/PCH_summer_SA_extent_WGS84.shp`), buffered
  by 2 grid cells. Cropped grid: 122 (south_north) x 169 (west_east) cells,
  lat 65.76-71.22, lon -149.76 to -130.95. 14973/20618 cells of the cropped
  bounding box fall inside the actual polygon; cells outside it are NaN
  (NetCDF) / nodata (GeoTIFF).
- **Projection**: WRF's native polar stereographic grid --
  `+proj=stere +lat_0=90 +lat_ts=64 +lon_0=-152 +x_0=0 +y_0=0 +R=6370000 +units=m +no_defs`
  (`dyndowntools.wrf_projection.WRF_STEREO_PROJ4`). NetCDF keeps geographic
  XLAT/XLONG coordinates (WGS84); GeoTIFFs are written in this projected CRS.

## Variables

| Variable | Description | Units | Daily aggregation |
|---|---|---|---|
| `t2_mean` | 2m air temperature | K | mean of 24 hourly values |
| `t2_min` | 2m air temperature | K | min of 24 hourly values |
| `t2_max` | 2m air temperature | K | max of 24 hourly values |
| `precip_total` | total precipitation (convective + grid-scale, `rainc`+`rainnc`) | mm | sum of 24 hourly deltas |
| `snow_00z` | snow water equivalent | kg m-2 | 00Z (00:00 UTC) snapshot |
| `snowc_00z` | snow cover flag | 1 | 00Z snapshot |
| `snowh_00z` | physical snow depth | m | 00Z snapshot |
| `smois_mean` | soil moisture, all 4 layers | m3 m-3 | mean of 24 hourly values |
| `tslb_min` | soil temperature, all 4 layers | K | min of 24 hourly values |
| `tslb_max` | soil temperature, all 4 layers | K | max of 24 hourly values |

`rainc`/`rainnc` are already hourly deltas in the source files (confirmed
against a rainy day: values fluctuate non-monotonically hour to hour, so
summing them directly gives the correct daily total -- no differencing
needed).

### Soil layers

`smois_mean`, `tslb_min`, `tslb_max` carry all 4 layers of the Noah LSM soil
scheme:

| Layer | Depth range | Center depth (NetCDF `soil_layers_stag` coordinate) |
|---|---|---|
| 1 | 0-10 cm | 5 cm |
| 2 | 10-40 cm | 25 cm |
| 3 | 40-100 cm | 70 cm |
| 4 | 100-200 cm | 150 cm |

In the NetCDF files, `soil_layers_stag` is a proper CF depth coordinate
(`standard_name=depth`, `units=cm`, `positive=down`), with layer bounds in
`soil_layer_depth_bounds`. In the GeoTIFFs, each of these variables' 4 bands
is labeled with its depth range (e.g. `"10-40 cm"`) via the GeoTIFF band
description.

## NetCDF files

One file per year: `akcasc_caribou_daily_<year>.nc`, dims `(time,
south_north, west_east)` plus `soil_layers_stag` for the soil variables.
`time` is daily (datetime64); `south_north`/`west_east` are index-only
(no 1D coordinate), with 2D `XLAT`/`XLONG` (degrees, WGS84) as the geographic
reference, matching the source files' convention. CF-1.8 conventions,
`zlib` compression (complevel 5).

Generated by `../scripts/extract_daily_vars.py`.

## GeoTIFF files

One file per variable per day, in a subfolder per variable:
`geotiff/<variable>/<variable>_<YYYY-MM-DD>.tif`, e.g.
`geotiff/t2_mean/t2_mean_2021-05-01.tif` (492 files/variable, 4920 total).
Single-band for all variables except `smois_mean`/`tslb_min`/`tslb_max`,
which are 4-band (one band per soil layer, see above). Nodata is `NaN`,
set automatically for cells outside the study-area polygon.

Generated by `../scripts/export_daily_geotiffs.py`, via
`dyndowntools.wrf_geotiff.to_geotiff()`.
